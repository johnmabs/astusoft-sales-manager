# TASK-00-02-02 — Create delivery templates

**ID:** TASK-00-02-02
**Status:** validated
**Owner:** Project Maintainer
**Parent Epic:** [EPIC-00-02](../EPIC.md)

## 1. Objective

Create reusable templates for Lots, Epics, Tasks and Gates
that comply with the delivery documentation contracts.

## 2. Motivation

Templates provide predictable structure and reduce missing
information across delivery records.

They must not contain broken links to future operational
documents.

## 3. Scope

### Included

- LOT.template.md.
- EPIC.template.md.
- TASK.template.md.
- GATE.template.md.
- Template usage rules.
- Placeholder reference policy.
- Correction of unresolved template links.

### Excluded

- Creation of operational delivery records.
- Automated lifecycle consistency validation.

- **TASK-00-02-01:** Delivery contracts available.
